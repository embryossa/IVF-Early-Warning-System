# Демо-панель EWS на выгрузке другой лаборатории

Прочитай `CLAUDE.md` до начала. Это демонстрация: в таких выгрузках есть только данные
цикла — нет логов MIRI, лотов среды и прогонов Digital Twin/TabPFN. Поэтому работает
только абсолютный контур Венского консенсуса и относительный контур по базовой доле самой
выгрузки. **Числа считает Python** (`scripts/ews_demo.py`); твоя роль — оркестрация,
сопоставление колонок с подтверждением владельца и короткий комментарий по пакету агрегатов.

## Аргументы

`/ews-demo <путь к .xlsx|.csv> [--sheet N] [--ref-start YYYY-MM-DD] [--ref-end ...] [--window 20]`

Без пути — спроси файл. Если пользователь хочет «просто показать», предложи синтетический
пример: `python scripts/ews_demo_synth.py` → `data/sample/demo_clinic_synthetic.csv`
(в нём заложены провал BlR в августе–сентябре 2026 и эмбриолог с пониженным FR — система
должна их найти; это удобная проверка на презентации).

## Шаги

1. **Колонки, до расчёта.** `python scripts/ews_demo.py --input "<файл>" --check-columns`.
   Скрипт печатает только заголовки и сопоставление, строки данных не читаются в контекст.
   - Сопоставление — только точные синонимы из `config/demo/column_aliases.yaml`.
     **Неизвестные имена не угадывать.**
   - Если есть «НЕОДНОЗНАЧНО» или не найдена ключевая колонка (2PN, Bl, Good Bl, ОКК, MII,
     дата пункции) — покажи пользователю кандидатов и спроси, какую взять. После ответа
     запиши override в `data/demo/<slug>/columns_override.yaml`:
     ```yaml
     canonical:
       patient_id: "Номер карты пациента"
     ```
     Если колонка встречается в выгрузках регулярно — предложи добавить синоним в
     `config/demo/column_aliases.yaml` (проверив, что он однозначен).
   - Метод оплодотворения распознаётся из одной колонки («IVF/ICSI») или из флагов (колонки
     IVF и ICSI со значением «Да»). Если нет ни того, ни другого — вкладка «Оплодотворение»
     честно пустеет; не подставляй метод из других полей.

2. **Прогон.** `python scripts/ews_demo.py --input "<файл>" [--columns <override>] [опции]`.
   ~20–45 с (подбор порогов CUSUM бутстрепом). Стоп-условия: ошибка скрипта, «после
   исключений не осталось циклов», отсутствие панели — не интерпретируй, разберись с колонками.
   Опорное окно по умолчанию — весь период (ретроспективная фаза I); если владелец назвал
   эталонный период — передай `--ref-start/--ref-end`.

3. **Комментарий ИИ.** Прочитай **только** `data/agent_packets/demo_<slug>.json` (агрегаты,
   без строк циклов и без имён). Напиши на русском 150–250 слов в
   `data/agent_packets/demo_<slug>_commentary.md`, три раздела:
   - `### Что видно` — факты с числами РОВНО из пакета;
   - `### Что это может значить` — гипотезы, каждая помечена как гипотеза, с перечнем
     проверок из `checks` (тексты консенсуса), не диагноз;
   - `### Ограничения` — ретроспективная фаза I, демо-калибровка, нет среды/лотов/конверта,
     поэтому независимого подтверждения нет; различия эмбриологов — с оговоркой о составе
     пациенток (`embryologists._casemix_*`).

4. **Состязательная проверка комментария** (правило, унаследованное из embryo-lab-data).
   Если доступен агент `interpretation-critic` — запусти его по комментарию и пакету.
   Иначе пройди чек-лист сам и исправь всё найденное:
   - каждое число совпадает с пакетом (включая округление);
   - нет гипотезы, поданной как вывод; нет «причины» из корреляции;
   - нет долей на вырожденных знаменателях (эпизоды из 1–2 циклов не трактуются);
   - CUSUM и EWMA одной метрики не поданы как два подтверждения;
   - `watch` не назван тревогой; `alert` в демо невозможен;
   - ClR>100% и MII>OCC не названы ошибками данных;
   - `Bl→Good` не сравнивается с порогами TGBDR;
   - ни слова оценки конкретного специалиста; имён нет (только псевдонимы из пакета).

5. **Панель с комментарием.** Повтори прогон с `--commentary data/agent_packets/demo_<slug>_commentary.md`
   (детерминированно: тот же seed даёт те же числа).

6. **Итог пользователю** (по-русски): путь к HTML (`data/demo/<slug>/EWS_Demo_<slug>.html`),
   3–5 главных наблюдений и что показать на презентации по вкладкам. Панель автономна
   (plotly встроен, ~6 МБ) и открывается без интернета; `--plotly cdn` — лёгкий вариант.

## Приватность

- Не читай исходную выгрузку целиком и не выводи её строки: для решения о колонках хватает
  `--check-columns`. ФИО, ДР, ID превращаются в `cycle_uid` и удаляются в ingest.
- Имена эмбриологов и врачей в панели — псевдонимы («Эмбриолог A»); таблица соответствия —
  только в `data/local_private/`, туда не заглядывай. `--show-operator-names` — только по
  явной просьбе владельца для внутреннего показа.
- Панель построена на данных пациенток другой клиники: **не публикуй её как Artifact** и не
  отправляй во внешние сервисы без явной просьбы. Синтетический пример — можно предложить.

## Чего здесь нет и не должно появиться

Остатков против конверта, покрытия P10–P90, лотов, MIRI, OZEMA, уровня `alert`. Если
пользователь просит «тревоги» — объясни, что демо-калибровка на той же выгрузке не даёт
права на `alert`; для боевой калибровки есть `/ews-backfit` на истории своей лаборатории.
